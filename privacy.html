오도노트(ODONOTE) 개인정보처리방침

시행일: 2026년 11월 20일 (개정: 앱 이름 변경, 차량·정비·지출 기록 추가)

오도노트(ODONOTE, 이하 "앱", 이전 이름: 모토로그)는 오토바이·자동차의 주행, 주유, 정비, 지출을 기록하는 앱입니다. 앱은 회원가입이 없고, 개발자가 운영하는 서버가 없습니다. 모든 기록은 이용자의 휴대폰 안에만 저장됩니다.

1. 휴대폰 안에서만 쓰는 정보

정보쓰는 곳저장 위치
위치 정보(GPS 위치, 속도, 방향)주행 경로, 거리, 속도, 기울기 계산과 지도 표시휴대폰 안에만 저장. 개발자에게 전송하지 않음
이용자가 고른 사진사진에 주행 기록을 얹은 이미지 만들기휴대폰 안에서만 처리. 이용자가 공유하거나 저장할 때만 밖으로 나감
주유 기록(금액, 리터, 주유소, 날짜)주유비 기록휴대폰 안에만 저장
카드 결제 알림 내용 (이용자가 켰을 때만)주유소 결제를 찾아 주유 기록으로 저장휴대폰 안에서만 처리. 주유소 결제로 보이는 알림만 앱이 읽을 때까지 잠시 보관하고, 그 밖의 알림은 저장하지 않음
차량 정보(이름, 종류, 주행거리), 정비 기록, 지출 기록차량별 정비 시기와 가계부휴대폰 안에만 저장
앱 설정, 주행 이름, 언어앱 기능휴대폰 안에만 저장

카드 결제 알림 자동 기록은 기본으로 꺼져 있습니다. 이용자가 설정에서 켜고 휴대폰 설정에서 "알림 접근"을 허용한 경우에만 동작하며, 설정에서 언제든 끌 수 있습니다. 알림 내용은 개발자나 외부로 보내지 않습니다.

백업 파일은 이용자가 직접 저장하거나 보낼 때만 만들어지며, 어디로 보낼지는 이용자가 고릅니다.

위치 정보는 이용자가 주행 기록을 시작했을 때만 사용하며, 주행 중에는 화면이 꺼져 있어도 기록되도록 알림을 띄운 상태로 위치를 받습니다.

2. 외부 서비스로 전달되는 정보

서비스전달되는 정보목적
카카오맵 (주식회사 카카오)지도에 보이는 지역의 좌표, 기기 및 접속 정보(IP 주소 등)지도 이미지 표시
OpenStreetMap (카카오맵을 쓸 수 없을 때)지도에 보이는 지역의 좌표, 접속 정보(IP 주소 등)지도 이미지 표시
Google AdMob (Google LLC)광고 ID, 기기 정보, IP 주소(대략적인 위치), 광고 반응 정보광고 표시, 광고 성과 측정, 부정 사용 방지
GitHub (GitHub, Inc.)접속 정보(IP 주소 등)앱 업데이트 확인과 내려받기

각 서비스의 정보 처리는 해당 회사의 방침을 따릅니다: 카카오 개인정보처리방침, Google 개인정보처리방침, OpenStreetMap 개인정보처리방침, GitHub 개인정보처리방침.

광고 맞춤 설정은 휴대폰의 설정 → Google → 모든 서비스 → 광고에서 광고 ID를 삭제하거나 재설정해 끌 수 있습니다.

3. 보관 기간과 삭제

주행·주유 기록은 이용자가 지울 때까지 휴대폰에 보관됩니다. 앱의 기록 → 편집에서 원하는 기록이나 전체 기록을 지울 수 있고, 앱을 삭제하면 모든 기록이 함께 지워집니다. 개발자는 이용자의 기록을 갖고 있지 않으므로 대신 지우거나 복구해 드릴 수 없습니다.

4. 권한

  • 위치(정확한 위치): 주행 경로 기록과 지도 표시
  • 알림: 주행 기록 중임을 알리는 알림 표시
  • 포그라운드 서비스: 화면이 꺼져도 주행 기록을 이어가기 위함
  • 인터넷: 지도, 광고, 업데이트 확인
  • 알림 접근 (선택): 카드 결제 알림으로 주유를 자동 기록할 때만

권한은 휴대폰 설정에서 언제든지 끌 수 있으며, 위치 권한을 끄면 주행 기록을 할 수 없습니다.
